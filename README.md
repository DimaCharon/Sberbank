# ChБанк — мобильное демо-приложение банка

Одностраничное мобильное веб-приложение «ChБанк»: баланс, карты, переводы, платежи,
история операций, чат с помощником и профиль. Без сборки и зависимостей — чистый
HTML + CSS + JS, работает офлайн из любой папки.

> Это учебное демо: деньги, получатели и операции виртуальные, состояние хранится
> в `localStorage` браузера. Настоящие платежи не проводятся.

## Запуск

```bash
# вариант 1 — просто открыть файл
open index.html

# вариант 2 — локальный сервер (нужен для камеры в QR-сканере)
python3 -m http.server 8080
# → http://localhost:8080
```

Код-пароль на экране входа — любые 4 цифры (кроме `0000`).

## Структура

```
index.html     разметка: 4 экрана, шторки, полноэкранные модалки, PIN
css/style.css  дизайн-система: токены, светлая/тёмная тема, анимации
js/app.js      состояние, рендер, переводы, платежи, чат, QR
```

## Что умеет

| Экран | Возможности |
|---|---|
| **Главная** | карусель карт, общий баланс со счётчиком, скрытие баланса, 4 быстрых действия, аналитика расходов, история с фильтрами, pull-to-refresh |
| **Перевод себе** | выбор суммы чипсами или на клавиатуре → мгновенное зачисление на выбранный счёт, конфетти и тост |
| **Перевод** | по номеру телефона (маска `+7 (916) 123-45-67`, имя получателя подставляется автоматически, формат «Ольга К.») или по номеру карты; сумма → подтверждение → обработка → чек |
| **Пополнение** | пресеты, ручной ввод, выбор счёта, экран успеха с новым балансом |
| **Платежи** | избранное, 32 услуги в 5 разделах, универсальный экран оплаты с чеком |
| **QR** | сканер (реальная камера через `getUserMedia` + демо-находка кода), мой QR-код |
| **Чат** | помощник с индикатором печати, быстрые вопросы, знает баланс/переводы/бонусы |
| **Профиль** | статистика, разделы настроек, тёмная тема, вибрация, сброс демо-данных |

## Анимации

счётчик баланса, пружинные шторки со свайпом вниз, ripple на всех кнопках,
каскадное появление списков, отрисовка галочки (stroke-dashoffset), конфетти,
сканирующая линия QR, индикатор активной вкладки, pull-to-refresh, вибрация
(`navigator.vibrate`), `prefers-reduced-motion` уважается.

## Адаптивность

Только мобильный форм-фактор: контейнер `max-width: 460px`, всё пропорционально
масштабируется через `clamp()`, `vw` и `aspect-ratio`; учтены `safe-area-inset`
(вырезы и «чёлки»), высота `100dvh`, медиазапросы для экранов `< 350px` и `> 420px`.

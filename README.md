# ChБанк — мобильное демо-приложение банка

Тёмный мобильный банк в стиле современных российских банковских приложений:
зелёные «обои» с бликами, стеклянные плитки кошелька, переводы по СБП,
экран успеха с градиентной галочкой. Без сборки и зависимостей — чистый
HTML + CSS + JS.

> Это учебное демо: деньги, получатели и операции виртуальные, состояние
> хранится в `localStorage`. Настоящие платежи не проводятся.

## Запуск

```bash
python3 -m http.server 8080   # → http://localhost:8080
# или просто открыть index.html
```

Первый вход — **регистрация**: телефон → код из СМС (любой) → имя и фамилия →
код-пароль дважды. Дальше вход по код-паролю (Face ID — кнопкой).

## Экраны (1 в 1 по референсу)

| Экран | Что на нём |
|---|---|
| Регистрация | 4 шага с прогресс-баром, маски телефона, код-боксы |
| Главный | аватар / поиск / чат / меню, «В кошельке» с глазом и «…», плитки: сканер+щит, счёт с картой, бонусы; промо-карточка с крестиком; «История · Ещё» |
| Счёт | обои с диагональными бликами, «Платёжный счёт •• NNNN», расходы за месяц, чипы [+][Pay][МИР], квадраты «Перевести / Пополнить / Оплатить», «Условия тарифа», «Совместный счёт» |
| Шторка «Перевести» | зелёная плитка «Новый перевод» с бейджем СБП, контакты, шаблоны, автопереводы, «Между своими счетами», «В другую страну», ссылка «Перейти в платежи» |
| Новый перевод | получатель (телефон с маской + имя в формате «Ольга К.», автоподстановка), банки с зелёной рамкой у выбранного, «Сколько», чипсы сумм, «Откуда» с зелёным ₽, «Сообщение», согласие с СБП, зелёная кнопка |
| Успех | карточка: градиентная галочка, «Перевели», сумма + значок СБП, «Комиссия 0 ₽», получатель, белая «На главный», тёмная «Чек»; ниже серая плашка с маршрутом перевода |
| История | push-экран: фильтры, группировка по дням, отказы «Недостаточно средств» оранжевым, чеки по тапу |
| Накопления / Для жизни / Платежи / Кредиты | 5 вкладок нижней навигации как в референсе |

## Механики

- **Перевод себе / пополнение**: сумма чипсом или с клавиатуры → мгновенное
  зачисление, экран «Пополнили», баланс пересчитывается счётчиком.
- **Перевод по телефону**: маска `+7 (___) ___-__-__`, имя получателя
  подставляется автоматически (формат «Ольга К.»), банк-получатель, СБП,
  подтверждение, обработка, чек; при нехватке средств операция падает в историю
  со статусом «Недостаточно средств» (оранжевым, как в референсе).
- Между своими счетами, оплата 12 услуг, QR-сканер с авто-находкой кода,
  чат-помощник, поиск, профиль с настройками, скрытие баланса, вибрация.

## Анимации

счётчик баланса, push-переходы справа, пружинные шторки со свайпом вниз,
отрисовка галочки (stroke-dashoffset), каскад строк истории, подсветка новой
операции, ripple на кнопках, сканирующая линия QR, код-боксы регистрации,
`prefers-reduced-motion` уважается.

## Адаптивность

Только телефоны: `max-width 480px`, `clamp()`-типографика, `100dvh`,
`safe-area-inset`, сетки услуг и медиазапросы для узких (`<350px`)
и низких (`<660px`) экранов — всё пропорционально.

## Структура

